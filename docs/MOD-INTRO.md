# 云音乐（yunyy）模组介绍文案（草稿，供修改）

## 一句话简介

在《我的世界》里直接听歌：支持网易云音乐、酷狗音乐（含概念版）、QQ 音乐点歌、歌单与账号 VIP 状态，可全服同步聆听，也可自由独享。

## 完整介绍（模组列表 / README 用）

云音乐（yunyy）让你在《我的世界》里直接听歌，无需切出游戏。

- **多平台点歌**：网易云音乐、酷狗音乐（标准版与概念版共用一套接入）、QQ 音乐，搜索即点即播；支持 `/music wyy 歌曲名`、`/music kg 歌曲名`、`/music qq 歌曲名` 指令点歌。
- **歌单导入**：登录账号后可直接拉取自己的歌单，一键把整张歌单加入播放队列。
- **账号状态**：自动读取本机设备指纹，可查看账号有效性与 VIP 状态。
- **三种歌词**：歌词按"原文 / 翻译 / 音译"三段式显示，可自由开关翻译与音译；歌词与播放信息 HUD 的位置、大小可自由调整，支持拖动与预设布局。
- **全服同步 / 个人聆听**：服务端玩家可共同聆听同一首歌，也可以切换为个人模式独自听歌；全服同步带时间戳校准，保证节奏一致。
- **自由听歌**：顺序、列表循环、单曲循环、随机四种播放模式随时切换；可开启游客模式，出站请求不携带登录凭证，仅播放免费公开歌曲。
- **服务端可控**：队列上限、点歌冷却均可由服主配置；管理员拥有清空队列、切换播放模式等专属权限。
- **开箱即用**：模组完全自包含，不依赖任何外部软件，跨电脑直接使用。
